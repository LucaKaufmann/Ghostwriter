# Documentation

This documentation is split by user journey so you can get to the right path quickly.

## What Should I Read First?

- If you want to run your own server, start with [Getting Started Overview](getting-started/overview.md).
- If you want the fastest supported installation path, go to [Ghostwriter with Docker](installation/ghostwriter-docker.md).
- If Ghostwriter is already running and you want to connect devices, go to [Connect Mobile Apps](getting-started/connect-mobile-apps.md).
- If you mainly want to read generated EPUBs on e-ink hardware, go to [KOReader installation](installation/koreader.md) and [E-ink readers](integrations/eink-readers.md).
- If you want to contribute code or docs, go to [Development and contributing](development/contributing.md).
