# Newsletters

Ghostwriter includes newsletter ingestion support so email-based reading can join the same digest workflow as your feeds.

## Best Use Case

Use newsletter ingestion when important content arrives in email rather than RSS.

## Rollout Advice

Start small:

1. Validate the base server and feed workflow first.
2. Connect newsletter ingestion.
3. Preview results before relying on it in your daily digest.

This avoids mixing email cleanup issues with core install or auth issues.
