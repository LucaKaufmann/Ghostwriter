# E-ink Readers

Ghostwriter is well suited to e-ink reading because the main artifact is an EPUB digest.

## Reading Options

Common paths include:

- syncing EPUBs into KOReader
- downloading EPUBs from the web UI and moving them manually
- opening digests in any EPUB-capable reading app on a tablet or phone

## Recommended Approach

- Use the web UI download flow first to verify EPUB quality.
- Once the digest output is stable, add automation such as KOReader sync.
