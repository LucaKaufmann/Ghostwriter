# Podcast Apps

If you enable Ghostwriter's podcast generation, podcast apps become another way to consume your daily briefing.

## Before You Subscribe

Confirm all of the following first:

- digest generation is reliable
- podcast generation succeeds
- the feed is reachable from the podcast app
- any public base URL is correct

## Practical Advice

- Test with one app first.
- Use a stable URL before adding the feed to multiple devices.
- If external apps cannot reach the feed, check reverse proxy and public URL configuration before changing AI or script settings.
