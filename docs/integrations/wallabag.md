# Wallabag

Ghostwriter can pull saved content from a Wallabag instance and include it in your digest workflow.

## What It Adds

Wallabag integration is useful when you want:

- a read-later inbox to feed Ghostwriter
- article content that is already captured and stored in your own system
- a separate stream from your normal RSS feeds

## Setup Expectations

Wallabag integration requires valid Wallabag credentials and endpoint details. Configure it only after the base Ghostwriter installation is healthy.

Recommended order:

1. Verify normal feed digests work.
2. Configure Wallabag.
3. Run a preview or small test.
4. Add it to your regular workflow.

## When to Use It

Use Wallabag when you want a curated personal reading queue rather than a pure feed-driven pipeline.
