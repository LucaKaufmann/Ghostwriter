The streamed response hash must match the finalized file before ownership is recorded. Only a newly finalized, recorded EPUB can be pruned, and only while its device/inode, size, modification time, and full SHA-256 hash still match. Missing or malformed ownership state, symlinked directory components, unsafe filenames, existing file collisions, and replaced files cannot authorize deletion. KOReader's `.old` settings fallback never grants ownership when the primary file is missing or corrupt. Unique partial files permit retry after interruption; finalization uses no-replace rename, hard link, or exclusive-create copy on filesystems without either. Directory-fd-relative operations prevent a replaced directory path from redirecting writes. Ledger updates precede unlink; settings saves verify the primary on-disk file because KOReader's flush does not report write failure. Failed saves leave cursors unadvanced.
