Result: PR104 comments `4115953288`, `4115953290`, and `4115953293` are addressed by a three-feed concurrency bound with ordered results, first-nonblank promotional input, and neutral partial wording. PR82 comment `4115924727` is addressed by exact scheduled-occurrence coverage persisted in `GenerationRun` even when no Digest is created. The Room 10→11 migration adds only nullable columns and leaves earlier runs unknown. Coverage is committed in the history/ledger or no-digest transaction: `complete`, `partial`, `empty`, and `deferred` cover; `failed` and `cancelled` do not. Existing `lastCatchUpDate` and WorkManager retry limits remain unchanged.

Periodic delivery uses one `daily_digest_*` WorkManager request per period. A newly registered request stores its first scheduled instant in input and carries a durable anchor-version tag. When migrating an unmarked legacy request, the scheduler observes `WorkInfo` off the main thread, waits for an active request to become ENQUEUED, then UPDATEs the same ID with its actual `nextScheduleTimeMillis` as anchor and one-shot schedule override. This preserves an overdue network-constrained occurrence instead of cancelling it. Once tagged, later app launches leave the existing input and anchor untouched, including after a delayed run shifts WorkManager's next schedule time. Disabling invalidates any pending registration and cancels the single unique request. The temporary `daily_digest_anchored_*` name existed only in an unshipped review branch and test fixture; no installed version needs migration from it.

Each new periodic attempt uses the latest nominal 24-hour slot from that fixed anchor; retries keep the original occurrence through the stable WorkRequest ID. Catch-up requests carry an explicit date. A legacy worker already executing with unanchored input retains its prior due-window interpretation for that attempt. These rules cover DST fall-back and work delayed across midnight without promising exact wall-clock dispatch. Late intervals coalesce to the latest nominal slot.
