## medium: Ghostwriter API cache is not thread-safe

app/src/main/java/com/example/epilogue/di/NetworkModule.kt

Run two threads repeatedly calling create() with two different MockWebServer base URLs, then invoke getHealth() through each returned API. With an unlucky interleaving, a returned API can target the other server or the cache can hold a mismatched API/baseUrl pair.
